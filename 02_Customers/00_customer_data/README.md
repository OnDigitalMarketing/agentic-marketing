# customer_data

**Source. Read only. Never committed.**

This folder is ignored by git. Put real files here on your own machine. Nothing in it reaches GitHub except this README.

## What goes here

| Example file | Where it comes from |
|---|---|
| Voice of customer (VoC) call logs and transcripts | Sales calls, support tickets, recorded customer interviews |
| Customer interview notes | Your own discovery conversations, one file per interview |
| Post-purchase or post-course survey exports | Typeform, Qualtrics, Google Forms, SurveyMonkey |
| Net Promoter Score (NPS) or satisfaction exports | Delighted, Pendo, your own form |
| Win and loss notes | Your customer relationship management (CRM) system |
| Churn and cancellation reasons | Billing system, exit survey |
| Persona and audience research | SparkToro, Sparktoro-style audience tools, analyst reports |
| Review text | G2, Capterra, Amazon, App Store, Google Business Profile |
| Community and forum threads | Reddit, Slack, Discord, your own community |

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_typeform_post-course-survey.csv`
`2026-09-28_interviews_ops-leader-manufacturing.md`

Date is the pull date or the interview date. Keep it in the filename so nobody has to guess how stale a file is.

## Before anyone analyzes this

Write down, for each file: what one row represents, what each column means, the date range, and the sample size. If you cannot answer those four questions, the file is not ready to be analyzed, and an agent asked to analyze it will invent the answers.

## Privacy

Strip names, email addresses, phone numbers, employers, and anything else that identifies a person before the file lands here. De-identified stays de-identified. Aggregates get reported out of this folder. Individual rows and verbatim quotes do not.
