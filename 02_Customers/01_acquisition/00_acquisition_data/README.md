# 00_acquisition_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- New customer lists with first-touch and last-touch source
- Spend by channel and period, including creative and staff cost if you track it
- Lead-to-customer conversion rates by source
- Sales cycle length by segment
- First order value by channel
- Your own Customer Acquisition Cost working file, usually a spreadsheet

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_crm_new-customers-by-source_q3.csv`

## Before anyone analyzes this

Know whether your source field is first touch, last touch, or self-reported at checkout. The three produce different answers and are frequently mixed in the same column.
