# 02_campaign_performance_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Cross-channel results pulled into one file: spend, impressions, clicks, conversions, revenue by channel and period
- The blended view that no single platform will give you
- Campaign calendars showing what ran when, which explains most unexplained spikes

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_all-channels_performance_q3.csv`

## Before anyone analyzes this

Platform-reported conversions sum to more than your actual total, because every platform claims what it can see. Reconcile against revenue before building anything on top of this file.
