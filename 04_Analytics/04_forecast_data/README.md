# 04_forecast_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Forecast spreadsheets and models, with their assumptions written down inside them
- Scenario versions: base, upside, downside
- Prior forecasts kept alongside actuals, so you can see how wrong you were
- Seasonality baselines

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_forecast_q4_base-case.xlsx`

## Before anyone analyzes this

A forecast without its assumptions visible is unusable by anyone but its author. Keep the old forecasts rather than overwriting them, because forecast accuracy over time is more informative than any single projection.
