# 02_cohort_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Cohort tables from Amplitude, Mixpanel, or a warehouse query
- Retention curves by acquisition month and by channel
- Repeat purchase intervals
- Feature or content usage by cohort

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_amplitude_retention-by-acquisition-month.csv`

## Before anyone analyzes this

State how many months of history each cohort actually has. A recent cohort with two months of data cannot be compared to a mature one, and charting them together implies it can.
