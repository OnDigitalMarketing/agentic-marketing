# 01_revenue_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Order and transaction exports from Shopify, Stripe, or your billing system
- Revenue by product, channel, and period
- Refunds, discounts, and chargebacks
- Contribution margin working files, including cost of delivery

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_stripe_transactions_q3.csv`

## Before anyone analyzes this

Revenue and contribution are different numbers, and marketing decisions need the second one. If cost of delivery is not in the file, the channel comparison you build from it will be wrong.
