# 01_Strategy

## What this folder is for

Positioning and the current operating plan. Positioning answers who we are for, what we do that alternatives do not, and why that matters to the buyer. The plan turns that into a sequence with dates and numbers.

## What lives here

| File | Status |
|---|---|
| `positioning-strategy.md` | Derived from customer data and market evidence |
| Operating plan (90 day or annual) | Derived |

## Before you start

Read `00_CMO/CMO.md`, then `02_Customers/icp.md`. Positioning written without the customer file in front of you is guesswork.

## How work gets done

1. Name the competitive alternatives, including doing nothing and the current workaround.
2. List the capabilities we have that those alternatives do not.
3. Translate each capability into value the buyer can feel. If you cannot, the capability is not differentiating.
4. Describe the best-fit account or buyer, with a qualification test someone could apply in a five minute conversation.
5. Name the market category the buyer already shops in.
6. Write the point of view underneath all five. If the positioning would still read as true with a competitor's name swapped in, it is not positioning yet.

## Output contract

Every claim carries its evidence and a date. Mark each as evidence, inference, or hypothesis. Keep a revision log at the bottom of the file with what changed and why.

## Guardrails

- Avoid commodity claims: AI-powered, data-driven, innovative, customer-centric, best-in-class, cutting-edge.
- Credentials are proof, not positioning. The customer is the protagonist.
- A positioning change is a material change. It needs approval before it goes anywhere public.

## Definition of done

Five components filled in, each traceable to something in `02_Customers`, and a revision log entry with today's date.
