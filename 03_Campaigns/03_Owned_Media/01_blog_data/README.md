# 01_blog_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Post-level performance: sessions, time on page, scroll depth, and conversions
- Publishing calendar with dates and authors
- Internal linking inventory
- Which posts rank, pulled from Search Console rather than guessed

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_ga4_blog-post-performance_last-90d.csv`

## Before anyone analyzes this

A post's traffic peak and its business contribution rarely arrive in the same month. Hold the measurement window open long enough to see both.
