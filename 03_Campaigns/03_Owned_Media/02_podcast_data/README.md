# 02_podcast_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Download and listen-through data by episode
- Platform breakdowns from Apple, Spotify, and your host
- Guest list with publish dates
- Referral traffic from show notes links

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_transistor_episode-downloads_q3.csv`

## Before anyone analyzes this

Downloads are not listens, and every hosting platform counts them differently. Compare episodes within one platform, never across two.
