# Paid_Search

Google Ads, Microsoft Ads, and any other pay-per-click search channel.

Read `../SKILL.md` before working here. Campaign plans and results live in this folder. Platform exports go in a `data/` folder alongside them, which git ignores.

State the acquisition cost ceiling before the first dollar is spent. It comes from Customer Lifetime Value and the margin you need, not from what the platform recommends.
