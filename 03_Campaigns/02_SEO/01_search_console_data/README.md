# 01_search_console_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Google Search Console performance exports, by query and by page
- Coverage and indexing reports
- Core Web Vitals and page experience exports
- Bing Webmaster Tools equivalents if you use them

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_search-console_queries_2026-05-01_to_2026-09-28.csv`

## Before anyone analyzes this

Search Console truncates and samples. Queries below a threshold are omitted entirely, so the totals will not reconcile with your analytics, and that gap is expected rather than an error.
