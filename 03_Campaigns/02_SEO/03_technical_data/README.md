# 03_technical_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Crawl exports from Screaming Frog, Sitebulb, or similar
- Core Web Vitals and PageSpeed Insights results
- Index coverage and sitemap status
- Redirect maps and broken link reports
- Structured data and schema validation output

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_screaming-frog_full-crawl.csv`

## Before anyone analyzes this

A crawl is a snapshot of one moment. Record the date and whether it ran against production or staging, because the two frequently disagree.
