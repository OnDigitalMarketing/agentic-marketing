# 02_competitor_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Semrush or Ahrefs competitor keyword and top-page exports
- Backlink profiles
- Share of voice and visibility trend exports
- Content inventories for competitors ranking above you

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_semrush_competitor-name_top-pages_us.csv`

## Before anyone analyzes this

Third-party traffic estimates are models built from clickstream panels. Treat them as directional ranking of competitors, never as their actual traffic.
