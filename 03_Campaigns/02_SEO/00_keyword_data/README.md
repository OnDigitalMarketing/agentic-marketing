# keyword_data

**Source. Read only. Never committed.**

This folder is ignored by git. Put real exports here on your own machine.

## What goes here

| Example file | Where it comes from |
|---|---|
| Keyword exports with volume, difficulty, and intent | Semrush, Ahrefs, Moz, Google Keyword Planner |
| Search Console performance exports | Google Search Console, query and page views |
| Competitor page and keyword pulls | Semrush, Ahrefs |
| Generative engine citation checks | Your own logged prompts and results |
| Rank tracking history | Your rank tracker of choice |

## Naming

`keyword-theme_report-type_market_YYYY-MM-DD.ext`

`ai-training-for-executives_all-keywords_us_2026-09-28.csv`
`competitor-name_top-pages_us_2026-09-28.csv`

## Generative engine checks are not reproducible

When you test whether an assistant cites you, log the exact prompt, the model and version, the date, and the full response. Run it again next week and you may get something different. That is the nature of the surface, and a screenshot with no prompt attached is not evidence.
