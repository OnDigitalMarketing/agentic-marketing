# 02_brand_mention_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Third-party mentions of your brand across the web
- Wikipedia, Wikidata, and reference site entries
- Review site and directory listings
- Podcast and article appearances, with dates and links

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_mentions_third-party-inventory.csv`

## Before anyone analyzes this

Corroboration across sources a model already trusts appears to matter more than anything on your own site. Track where you are absent, not just where you appear.
