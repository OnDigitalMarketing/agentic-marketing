# 01_prompt_test_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Your standing prompt set, the questions a buyer would actually ask an assistant
- The schedule you run them on
- Raw responses per model per date, saved as text
- Notes on how phrasing changes the answer

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_prompt-set_v2.md`

## Before anyone analyzes this

Keep the prompt set stable between runs. Changing the questions and the date at the same time means you cannot tell which caused the difference.
