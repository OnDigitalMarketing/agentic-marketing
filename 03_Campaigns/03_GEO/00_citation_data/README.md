# 00_citation_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Records of whether you were cited, one row per prompt per run
- The sources cited instead of you, which is the most useful column in this folder
- The model name and version, and the date, for every check
- Full response text saved alongside, never a screenshot on its own

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_chatgpt_citation-check_exec-ai-training.md`

## Before anyone analyzes this

One run proves nothing. Track the rate across repeated runs and always state how many runs are behind the number.
