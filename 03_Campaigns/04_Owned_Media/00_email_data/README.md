# 00_email_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Email platform exports covering sends, opens, clicks, unsubscribes, and bounces by campaign
- List growth by acquisition source
- Segment performance
- Automation and flow performance, reported separately from one-off campaigns

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_klaviyo_campaign-performance_q3.csv`

## Before anyone analyzes this

Open rate has been unreliable since mail privacy protection started inflating it. Judge on clicks and on what happened after the click.
