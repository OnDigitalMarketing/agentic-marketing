# 03_community_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Membership growth and active member counts
- Posts and replies per member
- Engagement by topic
- Support questions that repeat, which are product feedback wearing a different hat

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_circle_member-engagement_q3.csv`

## Before anyone analyzes this

Lurkers are the majority in every community. Counting only the people who post will misrepresent both the size and the health of the group.
