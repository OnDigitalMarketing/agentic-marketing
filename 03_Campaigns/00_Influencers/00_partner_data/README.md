# 00_partner_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Partner and creator lists with audience size and estimated overlap with your buyer
- Signed agreements and deliverable terms
- Tracked link performance, one row per partner per campaign
- Mentions, referral traffic, and discount code redemptions by partner
- Rate cards and quotes

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_partner-name_tracked-link-performance.csv`

## Before anyone analyzes this

Follower count is not audience overlap. Record how you estimated overlap, because that assumption drives the whole decision.
