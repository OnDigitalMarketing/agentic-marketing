# 00_YouTube_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Google Ads exports by campaign and video asset
- View rate, watch time, and the placement report
- Organic channel analytics, kept in a separate file from paid

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_google-ads_youtube-placements_last-90d.csv`

## Before anyone analyzes this

Separate click-through from view-through conversions before reporting anything. Blending them overstates the channel by a wide margin.
