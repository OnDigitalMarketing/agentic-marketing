# 00_Facebook_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Meta Ads Manager exports by campaign, ad set, and ad, with placement split out from Instagram
- Lead form submissions, and what happened to each lead afterward
- Audience and creative breakdowns

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_meta_facebook-leadforms_q3.csv`

## Before anyone analyzes this

Track leads through to a qualified conversation. Form fill counts are the easiest number here to mistake for progress.
