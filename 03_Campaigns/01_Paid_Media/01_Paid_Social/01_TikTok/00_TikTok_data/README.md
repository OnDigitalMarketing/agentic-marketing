# 00_TikTok_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- TikTok Ads Manager exports by campaign, ad group, and creative
- Video view, hold rate, and completion metrics
- Creative files with launch and retirement dates

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_tiktok_creative-performance_last-14d.csv`

## Before anyone analyzes this

Creative fatigues within one to two weeks here. An export covering ninety days averages away the only pattern that matters.
