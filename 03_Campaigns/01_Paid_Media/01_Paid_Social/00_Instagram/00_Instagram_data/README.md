# 00_Instagram_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Meta Ads Manager exports by campaign, ad set, and ad, with **placement split out from Facebook**
- Reels and Stories reported separately
- Creative files with launch and retirement dates

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_meta_instagram-reels-performance_last-30d.csv`

## Before anyone analyzes this

Meta blends Instagram and Facebook by default. If placement is not a column, the numbers describe neither platform.
