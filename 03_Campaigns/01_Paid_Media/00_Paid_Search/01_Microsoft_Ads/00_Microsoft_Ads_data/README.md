# 00_Microsoft_Ads_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Campaign, ad group, keyword, and ad exports
- The search terms report
- Search partner traffic, segmented from owned Bing traffic
- LinkedIn profile targeting breakdowns if you use them

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_microsoft-ads_search-terms_q3.csv`

## Before anyone analyzes this

Segment syndicated search partner traffic before judging the account. It usually converts worse than owned traffic and is included by default.
