# 00_LLM_Ads_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Whatever reporting the platform currently provides
- Your own log of where placements appeared, with the surrounding answer text
- Screenshots as a supplement to saved text, never instead of it
- The documentation version you planned against, since the rules change

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_llm-ads_placement-log.md`

## Before anyone analyzes this

This surface is unstable and the metric definitions change between quarters. Record which documentation you were working from, or next quarter's comparison will be meaningless.
