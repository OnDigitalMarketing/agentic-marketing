# 00_search_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Google Ads and Microsoft Ads exports by campaign, ad group, keyword, and ad
- The search terms report, which is the most useful file in this folder
- Auction insights and impression share reports
- Landing page performance by keyword
- Negative keyword lists

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_google-ads_search-terms_last-90d.csv`

## Before anyone analyzes this

Keep brand and non-brand separable. If the export does not distinguish them, add a column before you analyze it, because a blended cost per acquisition flatters the channel.
