# 00_Google_Ads_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Campaign, ad group, keyword, and ad exports
- The search terms report, which is the most useful file here
- Auction insights and impression share
- Landing page and asset reports
- Negative keyword lists

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_google-ads_search-terms_last-90d.csv`

## Before anyone analyzes this

Keep brand and non-brand separable, and note the campaign type. Performance Max blends search, display, YouTube, and Gmail into one row and will flatter the account.
