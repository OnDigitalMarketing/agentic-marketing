# 03_Campaigns/SEO_GEO

## What this folder is for

Two related problems. Search engine optimization (SEO) is being found in conventional search. Generative engine optimization (GEO) is being cited when someone asks an AI assistant instead.

## What goes in the data folders

`keyword_data` holds keyword exports with volume, difficulty, and intent, plus competitor page pulls. A separate `search_console` folder holds Search Console performance exports. Keep the pull date in every filename.

## Before you start

Read `02_Customers/icp.md`. Ranking for queries your buyer does not type is a vanity result, and it is the most common way this folder wastes a quarter.

## How work gets done

1. Pull what you currently rank for and who is actually arriving. Separate the queries that match the buyer from the ones that do not.
2. Name the gap between traffic you have and traffic you want. State it in clicks, not in rankings.
3. For GEO, test the questions a buyer would actually ask an assistant, record whether we appear, and record what gets cited instead of us.
4. Prioritize by buyer intent first and volume second.
5. Write the recommendation with an expected effect and a date to check it.

## The trap in this folder

Traffic that converts nobody is a cost. A page can rank first, bring thousands of visitors, and contribute nothing, and the report will still look like a win. Always carry the query through to what the visitor did next.

## Guardrails

- Heuristic SEO and GEO scores are estimates. Never present a tool's score as guaranteed visibility.
- Generative engine results vary by session and are not reproducible. Record the date, the model, and the exact prompt.
- Do not copy competitor content.

## Definition of done

Current state with a date, the gap in clicks, a prioritized list tied to buyer intent, and a check-back date.
