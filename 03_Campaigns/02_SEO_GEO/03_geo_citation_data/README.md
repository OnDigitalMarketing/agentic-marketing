# 03_geo_citation_data

**Source. Read only. Never committed.**

Git ignores every folder ending in `_data`. Only this README is tracked, so real files stay on your machine.

## What goes here

- Logged prompts you ran against AI assistants, with the full response saved
- Records of whether you were cited, and what got cited instead
- The model name and version, and the date, for every check
- Screenshots only as a supplement to the saved text, never instead of it

## Naming

`YYYY-MM-DD_source_short-description.ext`

`2026-09-28_chatgpt_ai-training-for-execs_citation-check.md`

## Before anyone analyzes this

Generative engine results are not reproducible. The same prompt returns different answers across sessions, models, and dates, so a check without the prompt, model, and date recorded is not evidence of anything.
