# 99_Outputs

The only folder where new files may be created.

Everything else in this repository is either source data you own or derived thinking you approved. This is the working area, and it is deliberately disposable. Git ignores its contents.

## Naming

`YYYY-MM-DD_area_short-description.ext`

The area is the folder the work relates to, in lowercase: `cmo`, `strategy`, `customers`, `campaigns`, or `analytics`. If the work spans more than one, use the main one.

`2026-09-28_customers_survey-summary.md`
`2026-09-28_campaigns_paid-media-test-plan.xlsx`
`2026-09-29_analytics_q3-channel-readout.md`

## Why this exists

An agent with permission to write anywhere will spread files across your system, and you will find them three weeks later with no idea which is current. One writable folder with dated filenames means you can always tell what happened when, and you can delete the whole folder without losing anything you meant to keep.

When something in here earns a permanent place, you move it into the right folder yourself.
